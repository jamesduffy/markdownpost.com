How to connect

Claude Code

claude mcp add --transport http markdownpost {{ endpoint }} \
  --header "Authorization: Bearer YOUR_TOKEN"

Any client that takes a JSON config

{
  "mcpServers": {
    "markdownpost": {
      "type": "http",
      "url": "{{ endpoint }}",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

Clients that only speak stdio can use a bridge such as mcp-remote with the same URL and header.
